# 前端 M7 实现说明：RAG 知识库前端

> 日期：2026-10-11 | 上游：[M7开发计划.md](M7开发计划.md) §8、[后端m7实现.md](后端m7实现.md)
> 范围：知识库管理页 /knowledge（上传/列表/删除）/ 对话页会话检索开关 / TracePane 检索区块 / mock 最小桩

## 1. 实现要点

### 1.1 契约对齐（types.ts / client.ts）

- `SessionSummary` 加 `rag_enabled: boolean`；新增 `KnowledgeDocument` / `RetrievalHit` / `Retrieval`；`Observability` 加 `retrieval: Retrieval | null`（两态）
- `LlmApi` 加 `setRagEnabled`（PATCH `{rag_enabled}`，与 renameSession 并存不动旧调用方）与 knowledge 三接口（上传用 FormData，multipart 字段名 `file`）

### 1.2 知识库管理页（KnowledgeView.vue + 路由）

- 独立路由 `/knowledge`（仿 /lab 先例）；el-upload 自定义 `http-request` 直调 api（accept=".txt,.md"）；el-table 列文件名/字符数/切块数/上传时间；删除走 ElMessageBox.confirm（文案注明历史调用链快照不受影响）
- 入口为 ChatView 标题栏「知识库」按钮（router.push），移动端随标题栏可达，未做专门窄屏适配

### 1.3 会话检索开关（ChatView.vue + stores/session.ts）

- 标题栏「知识库检索」el-switch：`:model-value` 单向绑定 + `@change`，**PATCH 失败时开关自动回弹**并 ElMessage 报错（不污染本地状态）；禁用条件 `streaming || sessionId === null`
- session store 加 `ragEnabled`：`openSession` 从列表项回显、`createSession`/`applyChatMeta` 默认关、`setRagEnabled` action 同步列表项；老 localStorage 存档无 rag_enabled 由 mock 侧归一化

### 1.4 TracePane 检索区块（debug/TracePane.vue）

- 遵守一期硬约束：只在 pane 内部加区块，DebugDrawer 容器与 TABS 不动
- `retrieval` 非 null 时渲染（位于压缩区块之前，两区块独立互不干扰）：descriptions（query / injected_tokens / latency_ms）+ hits 为空显示「未命中」el-alert、非空 el-collapse 逐片段折叠（标题 `[分数] 文件名`）；null 不渲染
- 原「无压缩记录」el-empty 改为 `v-else-if="!retrieval"`，避免有检索记录时误显空态

### 1.5 mock 最小桩（api/mock.ts，按 2026-10-11 规约）

- 预置两条假文档，上传/删除内存增删（char_count 用 file.size 充数），不持久化
- 会话 rag_enabled 内存可切（随 LS_SESSIONS 持久化，老存档 `??= false`）
- observability 的 retrieval：会话开了开关就返回一条固定假命中（query 取当前 user 消息），否则 null——不复刻真实检索行为
