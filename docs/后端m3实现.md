## 1. 已做（M3 范围）

| 模块 | 文件 | 内容 |
| --- | --- | --- |
| session_store | `server/session_store/base.py`、`sqlite_store.py` | SQLite 持久化（sessions / messages / settings 三表，技术方案 §4）；接口按类型化签名约定（不强制继承）；单连接 + 锁保证线程安全；外键级联删除 |
| chat | `server/chat/engine.py`（改造）、`server/chat/context.py`（新增） | 内存态会话全部换成 session_store 读写；滑窗截断：超 `n_ctx - max_tokens` 从最早对话对开始丢，system prompt 与当前输入始终保留 |
| params | `server/params/presets.py`、`server/api/params.py` | `GET/PUT /api/params`：默认值 + 三预设 + 范围校验；预设服务端展开；参数存 settings 表，重启不丢；chat 每次生成前读取，改参数不重载模型 |
| api | `server/api/sessions.py`（新增） | 会话 CRUD 五端点（§3.2） |

**token 统计落库**（2026-10-08 决策）：assistant 消息回填 `input_tokens`（近似值，坑点见 m2 文档 §4.3）与 `output_tokens`（精确）；`params_snapshot` 一期恒 NULL。

**已实测通过**：会话 CRUD 全端点；对话 → 停止（部分落库）→ 追问上下文正确（input_tokens 含历史）；**重启后会话/消息/参数均保留**；删除会话级联删消息；生成中卸载 409；参数 PUT（预设展开/显式覆盖→custom/非法值 400）；`max_tokens=20` 与 system prompt 对生成实际生效。

## 2. 接口增量（相对 M2）

### 2.1 会话（`api/sessions.py`）

- `GET /api/sessions` → `[{"id","title","updated_at"}]`，updated_at 倒序
- `POST /api/sessions` `{"title"?}` → 会话对象（缺省标题「新会话」）
- `GET /api/sessions/{id}/messages` → `[{"id","role","content","created_at"}]`
- `PATCH /api/sessions/{id}` `{"title"}`（空标题 400 `EMPTY_TITLE`）
- `DELETE /api/sessions/{id}` → `{"deleted": id}`，级联删消息
- 会话不存在统一 409 `SESSION_NOT_FOUND`

### 2.2 参数（`api/params.py`）

- `GET /api/params` → `{temperature, top_p, top_k, repetition_penalty, max_tokens, system_prompt, preset}`
- `PUT /api/params`：部分字段补丁；`preset`（precise/balanced/creative）服务端展开，显式字段优先于预设值；最终值不命中任何预设时 `preset=custom`
- 校验失败 400 `INVALID_PARAMS`；未知预设/未知字段同 400

### 2.3 行为变化（前端注意）

1. **会话不再是内存态**：重启后历史仍在，`SESSION_NOT_FOUND` 只在会话真被删除时出现
2. **空会话可存在**：`POST /api/sessions` 建的空会话，首次 chat 时用首条消息前 20 字自动命名
3. **chat 的 meta/done 语义不变**，契约零改动；messages 接口不返回 token 字段（可观测性二期再暴露）

## 3. 错误码表（增量）

| code | HTTP | 触发场景 |
| --- | --- | --- |
| `EMPTY_TITLE` | 400 | 重命名为空标题 |
| `INVALID_PARAMS` | 400 | 参数越界 / 未知预设 / 未知字段 |
