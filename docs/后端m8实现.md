# M8 后端实现说明：身份微调（QLoRA）

> 日期：2026-10-14 | 状态：已竣工
> 计划见 [M8开发计划](M8开发计划.md)；训练过程全量记录见 `server/finetune/training_record_m8.md`（本文不重复）。

## 1. 交付物与验收结论

- **最终模型**：仓库根目录 `fkjs-14b-q4_k_m.gguf`（9.0GB，Q4_K_M，源自 Windows checkpoint-150，epoch ~2.5 eval 谷底）
- **验收**：身份直问/绕过/边界/通用 llama-cpp 实测 **8/8 全对、无串戏**；tool calling 回归 8 用例决策 8/8、JSON 与函数名 100%（基线 87.5%，反超）；结果存 `server/finetune/tool_calling_regression.json`（过程产物不入 git）
- 已知瑕疵（不重训）：英文身份提问倾向中文回答

## 2. 数据管线（`server/finetune/`）

| 脚本 | 作用 |
| --- | --- |
| `gen_candidates.py` | MLX 4bit 模型批量生成身份问答候选（答案人工定稿） |
| `fetch_replay.py` | Belle 抽样通用 replay；tool replay 与 `tool_calling_spike.py` 定义严格对齐 |
| `build_dataset.py` | 五类数据（identity/bypass/boundary/replay_general/replay_tool）合并 + 划分留出集 |
| `render_check.py` | Qwen3 chat template 渲染抽查（防 think 块混入身份回答） |
| `eval_holdout_win.py` / `eval_identity.py` | 留出集评估（Windows / Mac MLX） |
| `tool_calling_regression.py` | GGUF 级 tool calling 回归对拍 |
| `train_loop_win.py` / `train_windows.py` / `train_loop.sh` | Windows 训练与守护续训 |

- 数据：`data/raw`（人工定稿三类）→ `data/curated`（五类 JSONL）→ `data/final`（训练/留出划分）；**身份回答一律直答无 think 块**（对齐线上 /no_think 口径）
- Windows 正式训练：QLoRA 4-bit NF4 + LoRA r=16，**lr 2e-4 × 4 epoch**，240 步零崩溃；round 1（lr 1e-4/1e-5 级 1 epoch）欠训练 0/10，教训：身份写入靠曝光量（epoch × lr），小数据 1 epoch 不够

## 3. 模型接入（多模型注册表，决策 C）

- `config.py`：`MODELS` 注册表（`qwen3-14b` 原版 / `fkjs-14b` 微调版）+ `DEFAULT_MODEL_ID`；原 `model_path` 字段删除（仅 manager 引用）
- `model_manager/manager.py`：`load(model_id=None)`——缺省沿用上次条目；非法 id 抛 `UNKNOWN_MODEL`；`_model_id` 记忆当前条目，status 下发。状态机不动，**切换 = unload → 带 id load**（前端串行，不加新接口）
- `api/model.py`：`POST /load` 接受可选 body `{"model_id"}`；`GET /status` 增返 `model_id` 与 `available_models`
- 前端：`ModelStatusBar` 加 el-select（`available_models.length > 1` 才渲染），store 增 `selectedModelId`/`selectModel`（已加载换条目 = unload→load）；mock 按 M7 决策只加最小桩

## 5. 坑点

- **Metal Internal Error**：mlx-lm fuse 后在部分提示词下崩溃（M8开发计划 §9），Mac 侧验证以 generate 冒烟为终点、不走 GGUF
- **lr 1e-5/1e-4 + 1 epoch 不写入身份**：小数据验证轮须给足 epoch（≥3）或 lr 上界 2e-4，否则留出集 0/10 假阴性
- 训练数据中 tools 块须与线上 spike 的 `<tool_call>` 格式逐字对齐，否则回归测试掉点
