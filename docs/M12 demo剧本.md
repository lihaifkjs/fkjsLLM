# M12 demo 剧本（四幕）

> 目标：让人看懂「专用模型在专业项目里哪里有用」——**知识走 RAG，能力走权重**。
> 四幕对应 [M12 方案](M12%20劳动法专有模型.md) §7.4；全部输出可用 `server/spikes/law_demo.py` 复现。

## 一句话主张

> 通用模型能背出法条名称，但你没法核对他背得对不对；领域模型不背法条，它**读检索到的条文并带出处**。

## 幕 ① 原版模型 · 无材料（裸考）

**配置**：`Qwen3-14B-Q4_K_M.gguf`，RAG 关
**问题**：我签的是三年期合同，公司说试用期八个月，这样合法吗？

**实际输出（摘录）**：

> 根据《中华人民共和国劳动合同法》第十九条的规定…**三年期劳动合同**：试用期不得超过 **6个月**。**一年期劳动合同**：试用期不得超过 **1个月**…
> **不合法**…根据《劳动合同法》第八十三条，用人单位违法约定试用期的，需承担以下责任…

**看点（这句一定要讲）**：它把法条**背错了一档**——「一年期合同→1 个月」是错的，法律规定是一年以上不满三年为**二个月**。而它语气笃定、还给出了第八十三条。
> 台词：「它看起来像知道，但你没法核查——它连分档都记错了。」

## 幕 ② 原版模型 · 有材料

**配置**：同一模型 + 注入检索到的 3 条（第十九条 / 第八十三条 / 第七十条）
**同一问题**

**实际输出（摘录）**：

> 根据《中华人民共和国劳动合同法》第十九条的规定…试用期不得超过**六个月**…您有权要求公司**补足超过法定部分的工资差额**…

**看点**：材料明明给了 3 条，它**一条都没引用**，仍然按自己的记忆组织答案（内容这次对了，但出处不可核查）；材料里的第七十条（非全日制不得约定试用期）被完全忽略。
> 台词：「给它资料 ≠ 它会用资料。这是 SFT 要补的能力。」

**量化对照**（60 题实测，见 [M12实现记录](M12实现记录.md)）：B 组引用命中 **0/40**，材料外引用 **20 题 / 45 处**。

## 幕 ③ law-14b · 有材料（训练后）

**配置**：`law-14b-q4_k_m.gguf` + 同一批材料

**实际输出（全文）**：

> 不合法。根据《劳动合同法》第十九条[1]，三年以上固定期限劳动合同的试用期不得超过六个月，公司约定八个月已超出法定上限。
>
> 可主张：要求公司按试用期满月工资标准，支付超过法定期间（即八个月减去六个月）的赔偿金（依据第八十三条[2]）。
>
> 适用条件：劳动合同期限为三年以上；试用期已实际履行。
>
> 免责：具体赔偿金额需结合实际工资标准计算，建议保留工资证明及合同文本。

**看点**：① 结论 → ② 依据（**带条号出处**）→ ③ 适用条件 → ④ 可主张 → ⑤ 免责，五段结构；答案 180 字（原版 400+ 字）。
> 台词：「同样的材料，它把出处摆在每一句后面，读者可以逐条核对。」

**量化**：D 组引用命中 31/40（材料给对时 **31/31 = 100%**），材料外幻觉 2/60 = 3.3%。

## 幕 ④ 往知识库塞一条「真法里没有」的规定

**配置**：law-14b + RAG，临时往知识库注入虚构条文：
《劳动合同法》第一百三十二条（**真实法律里不存在这一条**，真法只有 98 条）

**新问题**：公司用电子形式订立劳动合同，但不给我可以下载打印的完整合同文本，可以吗？

**检索结果**：`第一百三十二条`（0.81）居首
**实际输出**：

> 不合法。公司必须提供可下载、打印的完整电子合同文本（《劳动合同法》第一百三十二条[1]）。
> 可主张：要求公司补发完整合同文本；若公司拒绝，可向劳动行政部门投诉，要求责令改正（《劳动合同法》第八十一条[3]）。

**看点（这一幕是全场核心）**：模型不可能「背过」第 132 条——它不存在。它只能从我们刚塞进去的材料里读出来。
> 台词：「知识不在模型里。改库里的内容，重问就变。这就是为什么法条必须走 RAG。」

**收尾**：删掉那条虚构条文，重问即恢复「材料不足」——库变了，答案跟着变，权重没动。

## 演示注意事项

1. **CPU 推理很慢**：本机 llama-cpp 是 CPU 版，单题 1.5~3 分钟。现场一问一答会冷场。
   → 建议**提前跑好录屏/截图**，现场只讲解；或只现场演示幕 ③④（短答案，约 100 秒/题）。
2. **幕 ④ 的问法要对**：问句要和注入的条文有足够语义重叠，否则检索不到（实测「APP 点同意」这种口语问法召回失败，换「电子形式订立 / 可下载打印的完整文本」才命中）。
3. **跑完自动清理**：脚本用 `try/finally` 删掉虚构条文，知识库恢复原状（当前库只有两部真法 136 条）。
