# 前端 M4 开发计划（移动端响应式适配 + 联调验收准备）

> 状态：待评审 | 日期：2026-10-08
> 依据：[prd.md](prd.md) §3.5 / §6 里程碑 M4、[技术方案.md](技术方案.md) §5.4；遗留项见 [前端m3实现.md](前端m3实现.md) §5
> 已确认（2026-10-08）：验证方式为 mock 模式 + 浏览器模拟手机视口；真机局域网联调留待 Windows 部署后由用户验收
> 范围：纯前端改造，**后端零改动**；「生效参数快照」调试标签页属二期，不进 M4

## 1. 目标与断点约定

- 桌面（>768px）：现有双栏布局**零变化**，只做回归
- 移动端（≤768px，PRD 3.5）：单栏布局 + 抽屉式会话列表 + 软键盘适配
- 断点统一：新增常量 `MOBILE_BREAKPOINT = 768`（px），JS 用 `matchMedia` 侦测（新 composable `composables/useIsMobile.ts`），CSS 媒体查询用同一数值，避免双口径

## 2. 改造清单

### A. 会话列表抽屉化（核心，M3 遗留项）

- `ChatView.vue`：顶栏左侧加汉堡按钮（`v-if="isMobile"`），点击打开 `el-drawer`（`direction="ltr"`，size 260px），抽屉内复用现有 `SessionList` 组件（桌面侧栏与移动抽屉共用同一组件，行为一致：生成中拦截切换/删除/新建）
- 选中会话 / 新建会话成功后自动关闭抽屉：`SessionList` 新增 `selected` emit，`ChatView` 监听后关闭（桌面端监听无副作用）
- `SessionList.vue`：操作图标（重命名/删除）目前 hover 才显示，移动端无 hover——`@media (max-width: 768px)` 下常显
- 删除现有 `.sidebar` 的 `@media` 隐藏规则，改为 `v-if="!isMobile"` 渲染侧栏（CSS/JS 断点统一走常量）

### B. 软键盘与小屏视口适配（PRD 3.5 点名）

- `ChatView.vue` 高度 `100vh` → `100dvh`（兜底 `100vh` 在前）：iOS Safari 软键盘弹出时布局随可视区收缩，输入框不被遮挡
- `index.html` viewport 加 `viewport-fit=cover`，`style.css` 加 `env(safe-area-inset-bottom)` 适配 iPhone 底部横条
- `ChatInput.vue`：`el-input` 加 `enterkeyhint="send"`（手机键盘回车显示「发送」）
- 模拟视口验证时软键盘行为无法真实复现，此项以代码走查 + 真机验收为准（记入验证清单）

### C. 小屏布局细节

| 位置 | 问题 | 改法 |
| --- | --- | --- |
| `ChatView` 顶栏 | 标题 + 参数按钮 + ModelStatusBar 一行挤不下 | 标题 `min-width: 0` + 省略号截断；小屏减小 header 内边距 |
| `ModelStatusBar` | 显存文本、加载中提示文案过长 | ≤768px 隐藏 `显存 xxx MB` 文本；加载中提示精简为「加载中…」（长文案仅桌面显示） |
| `ParamsView`（右侧 drawer） | 固定宽度在手机上过窄/溢出 | ≤768px 时抽屉宽度 100%（全屏） |
| `DebugDrawer` | 同上 | ≤768px 宽度 100% |
| `MessageBubble` / 消息区 | `padding: 16px 24px` 在 375px 宽下浪费 | 小屏 padding 减为 12px；气泡 max-width 放宽 |
| `ElMessageBox` 弹窗 | Element Plus 默认宽度适配移动端 | 仅验证，不改 |

## 3. 不做 / 不做假设

- 不改后端任何接口与配置（`0.0.0.0` 监听、dist 托管已就绪，见 技术方案 §5.5）
- 不做 PWA、手势滑动开关抽屉、横屏专门布局（PRD 未要求）
- 不动 DebugDrawer 的标签页结构（PRD 3.7：加标签页只允许加配置+写组件，本期不加）

## 4. 实施步骤

1. 新增 `composables/useIsMobile.ts`（matchMedia 侦测 + 常量导出）
2. `SessionList.vue`：`selected` emit + 小屏常显操作图标
3. `ChatView.vue`：汉堡按钮 + el-drawer + 侧栏条件渲染 + dvh + 顶栏截断
4. `ChatInput.vue`：enterkeyhint
5. `ModelStatusBar.vue`：小屏隐藏显存文本、精简加载文案
6. `ParamsView.vue` / `DebugDrawer.vue`：小屏抽屉全屏
7. `index.html` / `style.css`：viewport-fit + safe-area
8. 验证（§5）→ 更新文档（§6）

## 5. 验证方法（mock 模式）

- `npm run build` 通过（vue-tsc 零错误）
- 模拟手机视口（375×812，iPhone 尺寸）逐项过：
  1. 侧栏不显示，汉堡按钮打开抽屉，列表正常
  2. 抽屉内选中会话 → 抽屉自动关闭 + 消息加载
  3. 抽屉内新建 / 重命名 / 删除可用（操作图标常显可点）
  4. 加载模型 → 发消息 → 流式渲染、token/s 状态行、上下文占用显示均正常
  5. 参数抽屉全屏打开、滑块可拖、保存成功；调试抽屉全屏打开
  6. 长会话标题顶栏省略号截断，不挤爆布局
- 桌面视口（1440px）回归：双栏布局、参数抽屉宽度、会话列表 hover 行为与 M3 一致
- 代码走查项（模拟器不可验）：软键盘顶起布局（dvh）、enterkeyhint、safe-area
