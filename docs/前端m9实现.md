# 前端 M9 实现说明：网页搜索开关 + 中间态 + 调用链

> 日期：2026-10-14 | 上游：[M9开发计划.md](M9开发计划.md)、[后端m9实现.md](后端m9实现.md)
> 范围：会话级「网页搜索」开关 / SSE tool_call 事件中间态 / TracePane 工具区块 / mock 最小桩

## 1. 实现要点

- **类型与客户端**（`api/types.ts` / `client.ts`）：`ChatSseEvent` 加 `tool_call`；`ToolCallEvent` / `ToolCallResult` / `ToolCallRecord` 类型；`SessionSummary` 加 `tool_enabled`；`Observability` 加可空 `tool_call`；`LlmApi` 加 `setToolEnabled`（PATCH 部分更新）
- **store**（`stores/session.ts`）：`toolEnabled` ref 随 `select()` 切换会话回显；`setToolEnabled` 仿 `setRagEnabled`（成功后列表项同步）；新建/首聊会话默认关
- **开关**（`ChatView.vue`）：头部「网页搜索」el-switch 与知识库检索并列，`:model-value` 单向绑定 + PATCH 失败回弹同款
- **中间态**（`useChatStream.ts` + `MessageBubble.vue`）：`tool_call` 事件置 `searchQuery`，回答轮首个 token 到达即清除（无结束事件，后端契约如此）；`cleanup` 兜底清除。中间态渲染为气泡内「正在搜索：xxx…」呼吸闪烁行，仅传给流式中的最后一条气泡
- **TracePane**：网页搜索区块（工具名/搜索词/状态三文/注入 tokens/耗时 + 结果折叠列表，正文优先 snippet 兜底）；`success` 但 results 空显示「搜索无结果」；null 不渲染；el-empty 条件加 `!toolCall`
- **mock 最小桩**（2026-10-11 规约）：开关可切换持久化 + observability 固定假 tool_call（开开关时），不模拟搜索行为、不发 tool_call SSE 事件
