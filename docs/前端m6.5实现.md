# 前端 M6.5 实现说明：摘要压缩前端

> 日期：2026-10-10 | 上游：[M6.5开发计划.md](M6.5开发计划.md) §7、[后端m6.5实现.md](后端m6.5实现.md)
> 范围：策略切换下拉 / 调用链标签页填实（TracePane）/ 被压缩消息有损标识 / mock 全链路自洽模拟

## 1. 实现要点

### 1.1 契约对齐（types.ts / client.ts）

- `InferenceParams` 加 `context_strategy: 'sliding_window' | 'summary'`
- `Observability` 加 `compression: CompressionInfo | null`（三态：`CompressionRecord` 完整记录 / `{triggered:false, active_id}` 复用 / null）
- **破坏性变更**：`getSessionMessages` 返回 `SessionMessages = {messages, summary_covered_upto}`；消费点同步改（session store、mock）

### 1.2 策略切换（ParamsView.vue）

- 「上下文策略（M6.5）」`el-select`：滑窗硬截断 / 摘要压缩（选项文案自带一句有损说明）；`onSave` 补丁加字段
- `paramFields.ts` 的 `validateParamFields` 加枚举条件校验（仅当字段存在时查，实验场四参数复用不受影响）；`ParamsSnapshotPane` 加一行展示

### 1.3 调用链标签页（TracePane.vue 替换 PlaceholderPane）

- 遵守一期硬约束：只「加配置 + 写组件」（DebugDrawer TABS 改一行），容器与消息列表不动；PlaceholderPane 删除（已无引用）
- 数据源复用 `useObservability`；三态渲染：
  - 触发：descriptions（事件/tokens 对比/耗时/覆盖范围）+ token 对比条 + el-collapse 折叠区（产出摘要 / 既有摘要 / 压缩前完整 prompt）
  - 复用：`复用既有摘要 #id（本轮未触发新压缩）`
  - 无：`el-empty` 降级
- 模板里 TS 无法从「record 为空」反推三态收窄，复用分支单独用 `reuseId` computed

### 1.4 有损标识（MessageBubble.vue / ChatView.vue / session.ts / useChatStream.ts）

- session store 加 `summaryCoveredUpto`（随 openSession 下发）；`refreshCoverage()` 在一轮 done 后只刷新游标不动消息列表，标识当轮即时出现
- ChatView 给气泡传 `compressed = coveredUpto !== null && message.id > 0 && message.id <= coveredUpto`（`id > 0` 排除本地临时负 id 误标）
- 标识样式：气泡褪色（opacity 0.55）+「已纳入摘要」角标（title 提示细节不再进入上下文）；原文不删不改

### 1.5 mock 自洽（api/mock.ts）

- `StoredSession` 加 `compressions` / `coveredUpto`，老存档读取时 `??=` 归一化；压缩记录随 `LS_SESSIONS` 持久化（不新增 LS 键）
- `maybeCompress` 复刻后端语义：估算口径（字符/2 + 每条 4 token 开销）超 `8192 − max_tokens` 且历史 > N 轮 → 溢出段滤掉已覆盖 → 生成假摘要（拼接用户消息前 12 字作 topics）；触发轮次首 token 前停 25 帧（750ms）模拟压缩耗时（对齐后端 meta 帧在压缩后才发出）
- `buildObservability` 摘要感知：被覆盖历史不进 prompt_messages，替换为摘要 system 段；seg 三段之和 = input_tokens 的自洽约束保持
- `getSessionMessages` 的游标仅在当前策略为 summary 时下发（切回滑窗标识消失，对齐后端）
